Deepfake Detection

멀티모달 딥페이크 탐지 모듈

Period
2026.08–11
Team
TOBIG'S 멀티모달/CV 팀 · 4명
Role
딥페이크 탐지 모델 전담 · 비교 · 선정 · 추론 API
Model
이미지 CLIP-L/14 · 얼굴 CLIP + Xception · 음성 wav2vec2 XLS-R

투자 사기 탐지 서비스(브라우저 확장)에서 이미지 · 얼굴 영상 · 음성이 합성인지 판별하는 모듈을 맡았습니다. 학습 데이터에서 잘 맞히는 모델보다 처음 보는 데이터에서 성능이 유지되는 모델이 필요했기 때문에, 학습에 쓰지 않은 외부 데이터셋의 AUC를 1순위 기준으로 삼았습니다.

What I did한 일

  1. 이미지 · 얼굴 · 음성 후보 12종을 외부 데이터로 비교하고, 부트스트랩 신뢰구간 · 짝 비교로 차이가 우연이 아님을 확인했습니다.
  2. 영상통화 화질을 재현해 보니 저화질(360p 이하)에서는 우세 모델이 뒤집혔습니다. 얼굴 크기(170px)를 기준으로 모델을 자동으로 고르게 했습니다.
  3. 결과를 보기 전에 합격선을 고정한 서비스 벤치마크 8개 중 7개를 통과했고, 백엔드 · 웹 확장이 호출하는 API로 연결했습니다(판정 일치율 100%).

Key findingShortcut · 가짜 단서

상황

첫 파이프라인은 돌릴 때마다 결과가 크게 달라졌습니다. 이미지 내용을 보지 않는 FFT 기준선의 AUC가 실행마다 0.015 · 0.500 · 0.601로 흔들렸습니다.

의심

진짜 이미지가 일부 샤드에서만 뽑혀 파일 형식이 정답과 겹쳐 있었습니다. 합성 흔적이 아니라 JPEG/PNG를 보고 맞힐 수 있는 상태였습니다.

확인

모든 이미지를 384 JPEG로 다시 저장하자 기준선은 0.49로 우연 수준이 됐습니다. 그럼에도 비율 · 크기 두 숫자만으로 0.694가 나와 정사각 크롭으로 다시 학습했습니다.

Takeaway

가짜 단서 제거 모델 · 서비스 API 연결
