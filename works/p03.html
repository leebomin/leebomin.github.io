Pill Finder

Model
HyperCLOVA X(답변) · Qwen3 4B(판단) · Claude API(검토)

1인 가구가 남은 약을 확인할 때 쓰는 도구입니다. 공식 자료만 근거로 알약 후보를 찾고, 일반의약품에 한해 쉬운 말 요약과 질문 답변을 줍니다. 진단 · 복용 지시는 하지 않으며, 의료인 검수 전 데모입니다.

What I did한 일

  1. 계산 · 규칙은 코드, 답변은 HyperCLOVA X, 검토는 Claude API로 나눠 모델에게 맡기지 않을 것부터 정했습니다.
  2. 표현 목록에 걸리지 않은 응급 질문을 Qwen3 4B가 한 번 더 판단하게 해 감지율을 3/20 → 20/20으로 올렸습니다.
  3. 모든 답변에 근거 문단 또는 “공식 자료에 없음”을 표시하고(20/20), 개인정보는 확인 전 외부 전송을 막았습니다(9/10 가림).

Key findingEval set · 평가셋 먼저 고정

상황

‘삼켰’, ‘한꺼번에’ 같은 표현 목록만으로는 응급 질문을 3/20밖에 잡지 못했습니다.

의심

규칙을 고칠 때마다 직접 만든 질문으로 확인하면, 규칙에 맞춘 질문만 통과하는 착시가 생길 수 있었습니다.

확인

규칙을 보지 않은 에이전트가 쓴 새 질문 40개를 먼저 고정하고 그것으로만 평가했습니다. Qwen3 4B 판단을 더하자 20/20, 평가셋 안 추가 오탐 0, 응답 약 0.4초였습니다.

Takeaway

응급 질문 감지 3/20 → 20/20
