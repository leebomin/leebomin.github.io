Deepfake Detection

Multimodal deepfake detection module

Period
2026.08–11
Team
TOBIG'S Multimodal/CV team · 4
Role
Owned the detection models · comparison · selection · inference API
Model
Image CLIP-L/14 · Face CLIP + Xception · Voice wav2vec2 XLS-R

For an investment-fraud detection service (a browser extension), I owned the module that decides whether an image, face video or voice is synthetic. We needed a model that holds up on data it has never seen, not one that scores well on its training data, so the AUC on external datasets not used for training was the first criterion.

What I did

  1. Compared 12 image, face and voice candidates on external data, and used bootstrap confidence intervals and paired comparisons to make sure the differences were not chance.
  2. Reproducing video-call quality showed the winning model flips at low resolution (360p and below). The service now picks a model automatically by face size (170px).
  3. Passed 7 of 8 service benchmarks whose thresholds were fixed before seeing results, and connected the module to an API called by the backend and the extension (100% verdict agreement).

Key findingShortcut · fake cues

Situation

The first pipeline gave very different results on every run. The AUC of an FFT baseline that never looks at image content swung between 0.015 · 0.500 · 0.601.

Doubt

Real images had been drawn from only some shards, so the file format overlapped with the label. A model could answer by looking at JPEG vs PNG rather than synthesis traces.

Check

After re-saving every image as 384 JPEG, the baseline fell to 0.49, chance level. Aspect ratio and size alone still reached 0.694, so I retrained with square crops.

Takeaway

Fake cues removed · model connected to the service API

Internal validation scores can include the data cues the model learned, so I chose by AUC on unseen data. When candidates were close, I picked only after confidence intervals and paired comparisons showed the gap was real. AUC held, but at a fixed threshold the face detection rate dropped to 46%, so I also handed over the sample size needed for recalibration.

Takeaway
