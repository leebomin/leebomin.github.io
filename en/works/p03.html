LLM web app grounded in official documents

Model

A tool for people living alone to check leftover medicine. It finds pill candidates using only official sources and, for over-the-counter drugs only, gives a plain-language summary and answers questions. It never diagnoses or tells you what to take, and it is a demo awaiting review by medical professionals.

What I did

  1. Split the work: calculations and rules in code, answers by HyperCLOVA X, review by Claude API, deciding first what the model should not do.
  2. Had Qwen3 4B re-check emergency questions the keyword list missed, raising detection from 3/20 → 20/20.
  3. Every answer shows its source passage or “not in official sources” (20/20), and personal data is blocked from leaving before confirmation (9/10 masked).

Key findingEval set · fixed first

Situation

A keyword list (“swallowed”, “all at once”) caught only 3/20 emergency questions.

Doubt

Checking each rule change with questions I wrote myself risked an illusion: only questions shaped to fit the rules would pass.

Check

I first fixed 40 new questions written by an agent that had never seen the rules, and evaluated only on them. Adding Qwen3 4B triage gave 20/20, 0 extra false alarms in the set, and about 0.4 s per response.

Takeaway

Emergency detection 3/20 → 20/20
